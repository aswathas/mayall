# WHAT TO BUILD

## 1. AttackReplay.tsx — THE SIGNATURE MOTION PIECE (highest priority)
A Canvas 2D motion graphic that replays a real exploit simulation, per
section 10 of the contract. It is the centrepiece of the product.

API:
```tsx
export interface AttackReplayProps {
  trace: TraceNode | null;
  artifact: SimulationArtifact | null;   // from @helix/core
  /** ms; the piece length is 8000 */
  durationMs?: number;
  className?: string;
  onComplete?: () => void;
}
export function AttackReplay(props: AttackReplayProps): JSX.Element;
```
Rules that are checked:
- Every frame is a PURE FUNCTION of time. Implement `drawFrame(ctx, t, model)` as
  an exported pure function so a single frame can be rendered deterministically.
  No accumulating state, no per-frame counters, no unseeded Math.random().
- The preview loop computes `t = (performance.now() - startRef) / 1000` and
  calls drawFrame. That is the ONLY source of time.
- `await document.fonts.ready` before the first frame.
- Theme-aware: read colours from getComputedStyle(document.documentElement) at
  draw time so the light theme renders correctly; re-read on theme change.
- Storyboard exactly as written in the contract (5 shots, 8.0s, hold the final
  frame 0.8s). Node size encodes gas share. The repeated function must visibly
  spiral inward — that is the re-entrancy tell.
- Seed any randomness (e.g. the tick positions along the value path) with a
  small deterministic PRNG, fixed seed.
- Respect prefers-reduced-motion: render the final frame statically, no rAF.
- Include a replay control and a progress hairline.
- Clean up the rAF loop and any listeners on unmount.

## 2. TraceViewer.tsx
Renders the `TraceNode` tree as an expandable call tree.
- Rows show: depth indentation with a branch glyph (lucide `CornerDownRight` or a
  drawn SVG line — NOT emoji), contract name, function, gas, and value.
- Expand/collapse via the `.collapse` grid-rows technique (spatial continuity,
  never animate a measured height).
- Cheatcode frames (contract name `VM`) are dimmed and marked as harness
  calls — they are not contract behaviour.
- A node whose (contract, function) pair repeats deeper in the tree is the
  re-entrancy tell: mark it with the arterial colour and a short label.
- Show a "calls" counter per node. Keyboard accessible: buttons, not divs.

## 3. GasFlameChart.tsx
Horizontal proportional gas chart from `GasFlameNode[]` (recharts BarChart,
layout="vertical"). Bars grow from 0 with a 30ms stagger (the `.grow-x`
utility or a per-bar animationDelay). Labels use the mono face; the largest
consumer is tinted with the arterial signal. Include a tooltip with the gas
value and the share of the total.

## 4. StorageDiffInspector.tsx

## 8. LiveSimPanel.tsx
The live runner. Given a `scenarioId`:
- POSTs `/api/simulate` with `{ scenarioId }`.
- While running: a progress state with an elapsed timer, a live status line
  ("executing forge test…" / "parsing trace…" / "classifying patterns…"), and a
  live dot. Never a bare spinner with no words.
- On success: renders AttackReplay at the top, then a tabbed evidence area —
  Trace, Gas, Storage, Balances, Patterns, Raw (forge stdout/stderr in a mono
  block with a copy button).
- On error: names the problem and the recovery (e.g. "Foundry not found — run
  npm run setup:foundry").
- Also renders the report link and the forensic bundle download button
  (`/api/bundle/lab-<scenarioId>?scenario=<scenarioId>`).
- Accepts an `onResult` callback so a parent page can use the result too.
