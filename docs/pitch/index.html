A block explorer gives you the transaction, the value that moved and the addresses. It does not give you the call that re-entered, the slot that was rewritten, or the invariant that stopped holding. That reconstruction is the incident response work.

Six attack classes ship as live local reproductions, each with a deliberately vulnerable contract and a Foundry proof-of-concept. The taxonomy models sixteen attack vectors.

Ten detectors. Confidence, never certainty.

Every simulation is scored by ten pattern detectors. Each finding carries a confidence, a severity, a rationale and evidence pointers that are rendered verbatim in the report.

Some detectors key off narrative keywords. Two are deliberately weak, and we say so.

Front Running

Every multi-step artifact emits a 0.55 finding. A single-transaction local trace cannot observe mempool ordering: it infers, it does not detect.

Invariant / Logic Error

Fires only when the narrative uses one of five keywords. Its balance signal scores 0.50 and is gated out below 0.60.

Confidence is the maximum of the evidence floors a rule triggered — never a sum — and every rule is capped below 1.0.
A finding is only as strong as the evidence it lists · the report renders that evidence verbatim

The chain state is local. The execution is not.

Mayall does not fork mainnet, and does not claim to.

Real
  • Solidity contracts, compiled and executed by Foundry
  • EVM call traces, gas figures and revert paths
  • Storage diffs read inside the test with cheatcodes
  • Deterministic detector output over the captured trace
  • SHA-256 chain of custody over every exported file
Simulated
  • The chain is a local EVM, not mainnet state
  • Funds are test funds in a local simulation
  • Incident registry is seeded from public disclosures; losses rounded
  • Reproductions are our own contracts demonstrating the mechanism
  • Detectors are heuristics over one transaction: no bytecode, no mempool
What this means

Every trace, gas figure and storage write on screen came from the run in front of you. The incident registry is context; the execution is the evidence.

If a judge asks “is this real?” — the contracts, the EVM, the traces, the gas and the storage diffs are. The chain state and the funds are a local simulation. That distinction is the product, not a footnote.
